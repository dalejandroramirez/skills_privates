# Dependencias

Antes de agregar una librería:

1. Verificar si la funcionalidad ya existe en la biblioteca estándar.
2. Verificar si existe una dependencia aprobada.
3. Evaluar mantenimiento.
4. Evaluar seguridad.
5. Evaluar estabilidad.
6. Evaluar complejidad.
7. Evaluar el impacto de sus dependencias transitivas.

No introducir una dependencia para resolver problemas triviales.

No utilizar dos librerías diferentes para resolver la misma necesidad sin una justificación técnica.
