# Testing

## Principios

- Los tests deben ser deterministas.
- Los tests deben ser fáciles de leer.
- Los tests deben validar comportamiento.
- Evitar depender innecesariamente de infraestructura externa.
- Cada test debe tener una responsabilidad clara.

## Pirámide

Priorizar:

1. Tests unitarios.
2. Tests de integración.
3. Tests end-to-end cuando sean necesarios.

## Calidad

Los tests no deben existir únicamente para aumentar coverage.

Deben validar comportamientos importantes del sistema.
