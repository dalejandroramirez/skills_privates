# Documentación

## Funciones

Las funciones públicas deben documentarse utilizando:

- Summary
- Args
- Returns

## Summary

Debe explicar qué hace la función y su propósito.

## Args

Debe explicar los parámetros relevantes.

## Returns

Debe explicar qué representa el valor retornado.

## Comentarios

Los comentarios deben explicar el motivo o contexto de una decisión.

Evitar comentarios que simplemente repitan el código.
