# Estructura de Proyecto

## Principios

- Organizar por responsabilidad.
- Preferir organización por dominio cuando el proyecto lo requiera.
- Evitar carpetas globales que acumulen funcionalidades sin relación.
- Mantener los módulos cohesivos.
- Mantener una estructura predecible.

## Regla

La estructura del proyecto debe facilitar:

- Encontrar código.
- Entender responsabilidades.
- Modificar funcionalidades.
- Probar módulos.
- Incorporar nuevas funcionalidades.
